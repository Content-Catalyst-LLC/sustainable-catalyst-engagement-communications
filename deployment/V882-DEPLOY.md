# WordPress Engagement Bridge v8.8.2

Upload `sustainable-catalyst-engagement-communications-wordpress-v8.8.2.zip` from WordPress Admin → Plugins → Add Plugin → Upload Plugin. Select **Replace current with uploaded**. Refresh the existing Engagement test page with `[sc_engagement_communications]` and verify Contact, Feedback, Feature Suggestions, Channel and Support links. If Feature Suggestions is missing, confirm the page at `/feature-suggestions/` is a published public WordPress page. No changes to Contabo or PostgreSQL are required.

For the source repository, merge this release into the existing Mac clone, run backend tests, then commit and push to GitHub.
