SUSTAINABLE CATALYST — MEDIA & COMMUNICATIONS BRIDGE v8.8.6
===========================================================

WordPress installation
----------------------
1. Back up your existing plugin and your WordPress site.
2. Plugins > Add New > Upload Plugin. Upload the ZIP, and replace the current version.
3. Activate/confirm "Sustainable Catalyst — Media & Communications Bridge" v8.8.6.
4. On the Media page, use [sc_media] in a Shortcode block. The old [sc_press]
   continues to render the same Media page until you update the shortcode.
5. Visit Settings > Media & Communications and review the connected URLs:
   Substack: https://newsletter.sustainablecatalyst.com/
   YouTube:  https://www.youtube.com/@SustainableCatalyst
6. Connect your verified LinkedIn company/profile URL and other official social
   channels in Settings > Media & Communications. Leave unknown links blank.
7. Optionally configure a featured public YouTube video or playlist URL.
8. Check the page while signed out; confirm Subscribe, archive, YouTube and
   approved internal links, including keyboard and mobile behavior.
9. Update the site's menu to Media > /media/ and redirect any previous
   /channel/ and /press/ URLs via WordPress/hosting once verified.

What this does
--------------
- Provides [sc_media] Media landing page with Substack, YouTube, LinkedIn and social channels.
- LinkedIn gets a dedicated professional-network section.
- Configurable X, Instagram, Facebook, Threads, Bluesky, Mastodon, GitHub,
  and TikTok directory links. Unconfigured links never render as active links.
- Supports an on-demand native Substack subscription form (visitor clicks first).
- Displays up to 3 public RSS newsletter headlines, when public feed is reachable.
- Can embed one configured featured YouTube video or playlist after a visitor click
  using the privacy-enhanced youtube-nocookie.com player.
- Links only already-published, public WordPress pages for news/events/contact.
- Keeps all previous Engagement & Communications shortcodes and settings.

What this does not do
---------------------
- No Substack subscriber import, sending, or newsletter creation.
- No YouTube API sync or automatic newest-video retrieval.
- No LinkedIn/social media API sync, automated posting, social profile data
  collection, credential storage, or scraping.
- No private Workspace/Research/Engagement data or private API access.
- No plugin-controlled WordPress page creation, slug redirects, or menu edits.
- No background tracking or third-party browser requests until a visitor
  clicks a subscription or video action; server-side public RSS may be fetched.

If RSS fails the page still links to the newsletter archive and subscribe URL.
Substack stores and processes its subscriptions; YouTube hosts its videos.

MEDIA-02 — LIVE ACTIVATION AND REDIRECTS
---------------------------------------
1. WordPress > Settings > Media & Communications > MEDIA-02 Launch readiness.
   Check that the published /media/ page is detected, public, and contains
   [sc_media] (or temporary [sc_press] compatibility markup).
2. Test /media/ on a private/incognito browser. Check layout on mobile,
   keyboard navigation, public content, and active Substack/YouTube/social links.
3. Confirm your WordPress navigation item is labelled Media and points to /media/.
4. Check whether /press/ or /channel/ is still a real WordPress page. If so,
   preserve its content and decide separately before deleting/redirecting.
5. If no server/SEO redirect exists, enable the optional legacy-URL redirect
   checkbox and Save settings. It is OFF by default and redirects ONLY clean
   requests for exactly /press/ or /channel/, when the /media/ page is public
   with an approved Media shortcode and no source-page collision exists.
6. Verify exact HTTP 301 on a signed-out browser, and no redirect for other
   paths, queries, POST requests, previews or distinct existing pages.
7. Rollback: uncheck the redirect option; revert the WordPress slug/menu if
   necessary; restore the previous plugin ZIP from backup. Clear caches.

Does not configure your live WordPress site or prove public HTTP results.
No automatic site/menu edits, publishing, subscriber storage or distribution.
