# Engagement & Communications v8.8.1 — Public Page Preservation & Navigation Bridge

- WordPress plugin patch only; backend and database remain unchanged.
- Preserves existing Contact, Feedback, Channel, Support WordPress pages, URLs, forms and shortcodes.
- Renders links to existing **published, non-password-protected** pages if their slugs match contact/contact-us, feedback, channel or support. Missing/private pages are omitted.
- Existing shortcode `[sc_engagement_communications]` includes links; standalone `[sc_engagement_public_links]` also available.
- No routing changes, login/session changes, data copying, redirects or form interception.
- Public standalone launch URL is still separately configured in WordPress Settings → Engagement Bridge and requires real HTTPS.
