# v12.5.0 — Institutional templates and brand assurance

Verified predecessor v12.4.0: `ba9cd9da07f5ef98ebcbe82d9072fd2213a3d126`.

Default-off `SCEC_TEMPLATES_STAGING_ENABLED=0`; existing-service `/v1/institutional-templates/status` and POST `/preview` require bound service identity, allowlisted tenant and administrator role. Any dangerous flag denies access; seven live production gates remain pending. Successful API responses are JSON with the existing private/no-store, nosniff, no-referrer and deny-framing security headers, not HTML serving responses.

Six private authoring templates: newsroom, digest, research alert, press brief, webinar notice and publication summary. Fixed Sustainable Catalyst branding, English metadata, one h1, sequential h2 sections, descriptive source links and an explicit synthetic/unpublished notice are derived from reviewed fixture facts. No arbitrary HTML, scripts, styles, forms, images, remote resources or recipient fields. Every inserted text/attribute is escaped. No browser, frontend, WordPress or public renderer is changed.

Require an exact-hash v12.4 workflow with all four simulated reviews complete; otherwise withhold document and markup. Webinar/publication details additionally require typed v11.6/v11.5 fixtures and an exact current lineage node/pointer whose source digest matches the actual regenerated event/citation preview. Webinar kind, source references and explicit artifact revisions must match; event sequence is represented as seq:N in lineage. Missing optional facts or an ineligible event withholds the special template. Publication notices remain visible with their source links; DOI absence stays explicit. No author, DOI, speaker, event time or scientific claim is invented.

These templates are private authoring structures. Source policy channels are reported separately; creating a template does not grant consent or channel distribution approval, including when authoring a format beyond those channels. Delivery authorization, public rendering and publication remain false. Any future document server must independently apply the returned restrictive CSP/no-store headers; a string preview is not evidence of browser enforcement.

Structural checks follow the purposes described by W3C [headings and labels](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html) and [link purpose](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html) guidance. The output is not a WCAG certificate: no visual contrast, assistive-technology, keyboard or real browser certification is claimed. wcag_conformance_certified remains false; v12.6 adds a bounded translation/accessibility preflight separately.

Full normalized input fingerprints bind optional facts and the workflow hash; no persistence or live template installation. Publish, serve-public, send, install-template, activate, delete and federate remain503. No new dependencies, production records, database, credentials or protected16 changes. See deployment/V1250-DEPLOY.md. Full Mac/Contabo regression, source preflight, protected/source/archive hashes and exact-SHA loopback/shutdown gates must close before v12.6.
