# v8.6.0 bound identity security contract

Bound mode is opt-in to preserve coexistence with v8.5.0; set `SCEC_IDENTITY_MODE=bound` and random `SCEC_IDENTITY_SIGNING_KEY` (>=32 characters). Deploy only on a localhost port behind trusted service-to-service routing; do not expose externally. Tokens are compact `base64url(canonical_json).base64url(hmac_sha256(key,encoded_json))` with `v=1`, `aud=scec-engagement`, `sub` (service-verified reference), `org` (UUID), `roles`, `exp` (Unix seconds). Max token lifetime at verification is 24 hours; short expirations preferred.

Roles: viewer, contact_editor, support_agent, advisor, approver, administrator. Every authenticated non-health route is mapped to the least-privilege RBAC matrix in `app/identity.py`. Contacts/inquiries creation needs contact_editor; support read/write needs support_agent; advisory creation and transitions need advisor; approval decision needs approver; administrator is an override. Actor references in advisory/support workflow events must match signed `sub`. `X-SCEC-Organization-ID` must match signed org and configured allowlist before selecting records in bound mode.

Security/privacy boundaries: request-denial logs record an action and a truncated SHA-256 subject hash, not payloads, bearer tokens or contact details. No PII export, erasure, retention policy, field-level masking, session revocation, token registry, SSO/OpenID Connect, database RLS, or fully persisted security-event audit is provided. HMAC keys are single shared secrets; secure issuer governance, key lifecycle and credential distribution must be implemented before exposing APIs or enabling writes. Legacy mode uses v8.5 static service token and is not equivalent to verified actor/tenant identity. Do not treat a token signed by an untrusted issuer as independent human verification.

Acceptance gates: 71 passing unit/API tests; isolated PostgreSQL lifecycle, least-privilege DB grants, external identity issuer verification, token rotation/revocation, organization cross-read/write, GDPR/privacy program, and HTTPS reverse proxy controls remain before live writes.
