# v12.0.0 — Unified communication object lineage

Verified predecessor: v11.9.0 `60c2a49d537978a37312462ef46bc770d01fadbe`. Owner confirmed simulation-only v12 and v13 scopes; v13 remains gated on v12.9. V12-INTERFACE-REVIEW.md records the concrete compatibility and gap analysis performed before this implementation.

New existing-service `/v1/communication-objects/status` and POST `/preview` are default-off under `SCEC_OBJECTS_STAGING_ENABLED=0`, bound service identity, allowlisted tenant and administrator role. All dangerous flags deny access; seven live production gates remain pending. Commit, publish, send, activate, delete and federate remain503.

Schema scec.communication-object/1 links one research root to typed announcement/feed/alert/press/citation/event/partnership/embed/audience artifact references. Each frozen node retains research revision, explicit artifact revision, historical source release/hash meaning, declared source digest, registered provenance and exact parent digest pointers. Frozen tuples and nested frozen pointer models prevent ordinary in-memory field/list mutation. Canonical node digests are recomputed and checked from bounded facts. Output envelope hashes cover the normalized complete object.

Reject duplicate nodes or artifact revisions, missing/multiple roots, orphan/cyclic/unreachable lineage, cross-tenant pointers or nodes, cross-research revisions, unregistered root provenance, stale parent hashes, altered node facts and mismatched historical source release/hash meaning. No arbitrary raw payload dictionary or contact PII field is admitted. Source digests remain declared references, not proof of external authenticity or signatures; no source fetch occurs. The explicit independently_verified flag remains false. API validation recomputes hashes; Pydantic's deliberately unsafe model_construct/model_copy APIs are not an authorization boundary for trusted Python callers.

Historical v11 modules remain unchanged. Their hashes do not all cover the same projection: v11.0 source-manifest, v11.1 serialized-content, v11.3 input-projection, and the later envelope types are retained explicitly. Event integer sequence requires an explicit artifact-revision label; it is separate from research revision. The integration test preserves a digest generated by the actual v11.0 function under the same tenant.

No persistence, new service/database, dependencies, real users, WordPress/frontend changes or production operations. See deployment/V1200-DEPLOY.md. Close only after full Mac/Contabo regression, preflight, protected16 comparison, complete ZIP/source hash checks, exact-SHA loopback negative tests and shutdown evidence. v12.1 cannot begin before closure.
